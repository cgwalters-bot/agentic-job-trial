# agentic-job-trial

A scratch repository, nothing more. It exists to try calling
[cgwalters-forge/agentic-job](https://github.com/cgwalters-forge/agentic-job)'s
reusable workflow from a repository other than its own, as a new user
would, for an evaluation written on 2026-10-07 (see the evaluation issue
in that repository). `.github/workflows/example.yml` is that repository's
example caller with this repository's name in place of its own and the
workflow pinned by commit; `.github/agentic-job/` holds the bounds and
configuration files it names. `docs/` is a trivial target for the
scripted agent to change.

The Actions runs here are the trial's results. Nothing in this repository
is secret or meant to be reused.
